# Towelwise AI

YOUR IDE Built for Hyperspace. An IDE built from Code-OSS around three things the user builds: hyperspace, recall and learning. It works alongside the AI coding agents they choose without ever driving them.

## Language

**Towelwise AI**:
The IDE itself, the product people install.
_Avoid_: Towelwise (alone), the fork, the extension

**Agent**:
A third-party AI coding extension a person chooses to install and sign in to, such as Claude Code or Codex.
_Avoid_: Assistant, bot, plugin

**Agent panel**:
The vendor's own view where a person works with an agent.
_Avoid_: Agent window, chat

**Area**:
One of the places a panel can sit: the primary side bar, the editor area, the secondary side bar or the bottom panel.
_Avoid_: Column, part, region

**In use**:
An area that the layout puts something in: a side bar or the panel holding an agent, or the editor area, which is always in use. Hyperspace never hides an area that is in use.
_Avoid_: Occupied, active

**Chrome**:
The parts of the window that frame the areas, such as the activity bar, status bar, title bar and menu bar.
_Avoid_: UI, decorations

**Layout**:
Where a person wants their agents and terminals in the window: which area each one lives in, the columns and rows of the editor grid, and how much of the window each area takes up. The same in every project; applying it puts each item where it belongs.
_Avoid_: Arrangement, preset, workspace layout

**Hyperspace layout**:
A person's saved choice of which chrome, and which areas that are not in use, to hide in hyperspace. Everything in use stays, sized as the layout says.
_Avoid_: Snapshot, profile

**Hyperspace**:
A temporary state in which the window hides what the person chose to hide and keeps the layout's areas in use, until they restore.
_Avoid_: Focus mode, zen mode

**Restore**:
Leaving hyperspace and returning the window to how it was before the jump.
_Avoid_: Undo, reset

**Memory**:
What Towelwise AI has kept from work done inside it. Only approved items count, and nothing from outside the IDE enters it.
_Avoid_: Knowledge base, knowledge portal

**Recall**:
The part of Towelwise AI that keeps memory and brings it back when it is needed.
_Avoid_: Hindsight, knowledge portal

**Guide**:
The part of Towelwise AI that provides learning, using lessons drawn from a person's own work.
_Avoid_: Tutor, help

**Mailbox**:
Where captured items wait for a person to approve them into memory.
_Avoid_: Inbox, approval queue, review queue

**Export**:
A person's deliberate one-way copy of memory out to another knowledge bank.
_Avoid_: Sync, share
